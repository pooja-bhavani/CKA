### Day 5: 🚪 "Gateway to Success"
**Learning Goal**: Master Gateway API and modern ingress

**🎮 Challenge**: 
- Deploy your café using Gateway API
- Create custom domain: `mycafe.k8s.local`
- Implement different routes:
  - `/` → coffee shop homepage
  - `/api/` → barista API
  - `/admin/` → management dashboard
- Add traffic splitting (90% stable, 10% beta)
- Show your café running on the custom domain
